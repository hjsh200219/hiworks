# 하이웍스 자격증명 등록

**비밀번호를 채팅으로 묻지 않는다. 사용자가 채팅에 비밀번호를 붙여 넣으면 쓰지 말고, 노출됐으니 하이웍스에서 비밀번호를 바꾸라고 안내한다.**

**빠르게 끝내는 게 목표다 — 사전 점검 없이 아래 명령 하나를 바로 실행한다.** 이메일을 묻지 않는다.
인자로 이메일을 받았으면 `--email "$ARGUMENTS"` 를 붙이고, 없으면 붙이지 않는다(필요하면 명령이 입력 창으로 묻는다).

실행 직전에 한 줄만 말한다:
> 화면에 「Hiworks」 입력 창이 뜨면 이메일·비밀번호를 넣어 주세요. 비밀번호는 이 대화에 남지 않고 OS 키체인에만 저장됩니다. (이미 등록돼 있으면 창 없이 끝납니다)

```bash
uv run "${CLAUDE_PLUGIN_ROOT}/scripts/hiworks.py" setup
```

Bash 도구 `timeout` 은 **600000**(10분)으로 준다 — 사람이 입력하는 동안 기본 2분에 끊기면 안 된다.
`uv` 가 없다는 오류면 설치를 안내한다(대신 깔지 않는다): macOS `curl -LsSf https://astral.sh/uv/install.sh | sh` · Windows `powershell -c "irm https://astral.sh/uv/install.ps1 | iex"`. 처음 한 번은 의존성을 받느라 수십 초 걸릴 수 있다.

명령이 하는 일: 이미 등록돼 있으면 창 없이 세션만 확인한다. 아니면 이메일(필요할 때)·비밀번호 창 → 로그인 1회로 확인 → **맞을 때만** 키체인에 저장. 2단계 인증 계정이면 인증 코드 6자리 창이 한 번 더 뜬다.
**실패해도 같은 명령을 자동으로 다시 돌리지 않는다**(틀린 비밀번호·인증 코드 횟수가 쌓이면 잠긴다). 결과를 알리고 다시 할지 묻는다.

결과 읽기:
- `✓ 등록 완료` / `✓ 이미 등록돼 있습니다` → 한 줄로 알리고 끝.
- `△ 비밀번호를 확인해 키체인에 저장했습니다 … 세션은 아직 없습니다` → 비밀번호는 맞았다. 붙은 사유(인증 코드 오류, 브라우저에서 할 비밀번호 변경·2단계 인증 설정 등)를 한국어로 풀어 안내한다.
- `✗ 저장하지 않았습니다 — … ACCOUNT_NOT_FOUND` → 이메일 또는 비밀번호가 틀렸다.
- `✗ 입력을 취소했습니다` → 그대로 끝낸다.
- `✗ 입력 창을 띄울 수 없습니다`, 또는 사용자가 원격 접속(휴대폰 Remote Control 등)이라 창을 볼 수 없다 → 사용자가 **자기 터미널에서** 실행하게 안내한다(비밀번호는 화면에 안 찍히는 프롬프트로 받는다): `uv run "${CLAUDE_PLUGIN_ROOT}/scripts/hiworks.py" setup` — 경로는 실제 값으로 풀어서 보여 준다.
- `✗ 이 컴퓨터에서 쓸 수 있는 키체인이 없습니다` → Linux 서버 등. 환경변수 `HIWORKS_USERNAME`/`HIWORKS_PASSWORD` 를 안내한다.

다른 계정으로 바꾸거나 비밀번호를 새로 넣으려면 `setup --force`, 지우려면 `forget`.
